# RECICLADORA EL CHELE

Sitio web informativo desarrollado para **Recicladora El Chele**, con el objetivo de brindar información sobre la empresa, los materiales reciclables que recibe, sus servicios, ubicación y medios de contacto.

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una plataforma web moderna y responsiva que permite presentar de manera clara y organizada la información de la empresa. El sitio está orientado a mejorar la presencia digital de Recicladora El Chele y facilitar la comunicación con clientes potenciales.

## Objetivos

- Presentar información general de la empresa.
- Mostrar los materiales reciclables aceptados.
- Publicar los servicios ofrecidos por la recicladora.
- Facilitar el contacto con clientes y proveedores.
- Proporcionar una experiencia de navegación amigable en dispositivos móviles y de escritorio.

## Tecnologías Utilizadas

- Vue.js
- Vite
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Funcionalidades

- Página de inicio con información destacada.
- Sección "Nosotros" con la historia y misión de la empresa.
- Información sobre servicios ofrecidos.
- Datos de contacto y ubicación.
- Diseño adaptable para dispositivos móviles y computadoras.
- Navegación intuitiva mediante menú principal.

## Estructura General del Sitio

- Inicio
- Nosotros
- Servicios
- Materiales Reciclables
- Contacto

## Instalación

Clonar el repositorio:

```bash
git clone <url-del-repositorio>
```

Ingresar al proyecto:

```bash
cd recicladora-el-chele
```

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto en modo desarrollo:

```bash
npm run dev
```

## Estado del Proyecto

Proyecto en desarrollo como parte de las actividades de prácticas profesionales y fortalecimiento de la presencia digital de la empresa.
